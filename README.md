# Bar-Ilan University Machine Learning (89-511) Study Workspace

This repository contains the interactive exam simulator skill, past exam archives, practice sessions, and course references for **Bar-Ilan University Machine Learning (89-511)**, taught by Prof. Gal Chechik & Prof. Joseph Keshet.

---

## 🚀 Interactive Exam Simulator Skill

- **Skill Location**: `.agents/skills/biu-ml-exam-practice/SKILL.md`
- **Skill Name**: `biu-ml-exam-practice`

### Core Capabilities:
* **Interactive Exam Simulation**: Generates exam questions based on actual BIU past exam formats (2022–2025) and course topics.
* **4 Core Exam Archetypes**:
  1. *Supervised Learning & Matrix Calculus Derivations* (MLE/MAP, OLS/Ridge duality, Softmax gradients, MLP backpropagation).
  2. *SVMs, Lagrangian Duality & Kernel Proofs* (Hard/Soft margin, KKT conditions, Gram matrix PSD, kernel feature maps $\phi(\mathbf{x})$).
  3. *ConvNets, Deep Learning Mechanics & Optimization* (CNN spatial output dimensions, parameter counting, BatchNorm 4-step equations, Dying ReLU, ResNets).
  4. *Unsupervised Learning, PCA & Modern GenAI / Causality* (PCA reconstruction error, Autoencoders vs PCA equivalence, GMM EM algorithm, SimCLR $L_2$ blurriness, Judea Pearl $do$-calculus).
* **Bilingual Support**: Full simulation support in both English and Hebrew.
* **Strict Automated Grading**: Automated rubric evaluation with HTML score badges, detailed deduction feedback, and final grade tallies.
